httpx==0.27.0
brotli==1.2.0  # Bumped 2026-05-23 from 1.1.0 to close GHSA-2qfp-q593-8484 (DoS via crafted brotli decompression input). Required for httpx to auto-decompress ATO's `Content-Encoding: br` responses — without it, resp.text returns the raw compressed bytes mangled as UTF-8 (silently corrupted every fetched doc when we hit this on 2026-05-21). After bumping, run `pip install --upgrade brotli` once the current Stage 3 parser finishes.
